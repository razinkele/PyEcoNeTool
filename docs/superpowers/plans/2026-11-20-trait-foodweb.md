# Trait-Based Food Web Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a food web from a species × trait-code file (MS FS MB EP PR) on the Data Import page, as a faithful port of the R EcoNeTool trait model plus a derived size-table extension.

**Architecture:** `trait_foodweb.py` holds the model (tables, probability, adjacency) and the file parser that fills missing analysis columns and returns notes; it ends in `data_import.build_food_web`, like every other import route. `app.py` gains a card, a placeholder-biomass session flag and banners on the three pages whose results use biomass.

**Tech Stack:** Python 3.13, pandas, numpy, networkx, Shiny for Python 1.9, pytest.

**Spec:** `docs/superpowers/specs/2026-11-20-trait-foodweb-design.md`

## Global Constraints

- Link probability = minimum of MS×MS, FS×MS, MB×MB, EP×MS, PR×MS; link iff probability **> threshold** (strict); default threshold **0.05**.
- Exclusions (R): resource MS7 → 0; consumer FS0 → 0; consumer MS not in the size table → 0; no self-links. Without the extension the size table has consumer rows MS3–MS6 only.
- Extension (default **on**): consumer rows MS1 `[0.50,.05,.05,.05,.05,.05]`, MS2 `[0.80,0.50,.05,.05,.05,.05]`, MS7 `[0.20,0.20,0.50,0.80,0.95,0.80]` over MS1–MS6. MS7 stays never-prey.
- Orientation: model matrix is `[consumer, resource]`; EconetPy matrices are rows = prey. Transpose exactly once, in `trait_adjacency`.
- Vocabulary: MS1–MS7, FS0–FS7, MB1–MB5, EP1–EP4, PR0–PR8.
- Estimates when columns absent: fg rules (in order) FS0→"Primary producers"; FS2/FS5 with EP3/EP4→"Benthos"; MB2 (non-FS0)→"Zooplankton"; MB5 with MS4–MS7→"Fish"; EP3/EP4→"Benthos"; else "Consumers". bodymasses = 0.01·L³ g with L (cm) by MS1..MS7 = 0.05, 0.5, 3, 12, 35, 100, 200. met.types "ectotherm vertebrates" for Fish else "invertebrates". efficiencies 0.77 for FS0 else 0.906. meanB 1.0 for all.
- A present optional column must be filled for every species, else ValueError.
- Banner text, verbatim: "Biomass values are placeholders (1.0 for every species) — these results are not meaningful."
- Every new local module must be in `deploy/deploy.sh` RUNTIME (enforced by `test_every_local_module_app_imports_is_shipped_by_deploy`).

## Review Focus

- Codes typed in lower case or with surrounding spaces (`ms3`, ` FS1 `) → accepted after upper-casing and stripping (Task 2).
- Codes without the prefix (`3` instead of `MS3`) or out of range (`MS9`) → ValueError naming the column, the bad value and the valid codes (Task 2).
- Threshold outside `[0, 1)` or blank → notification, nothing loaded (Task 3).
- A trait file with only producers (all FS0) → the shared "no feeding links" ValueError (Task 2).
- Excel trait file with trailing blank rows / extra columns → loads; extra columns kept in `info` (Task 2).
